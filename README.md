¿Que es GitHub? Github es una plataforma en la nube que permite al desarrollador almacenar, gestionar y colaborar en proyectos de código fuente utilizando el sistema de control de versiones Git.

¿Que espero aprender al utilizar repositorios? Yo espero aprender conceptos esenciales, así como a crear espacios de trabajo(locales y remotos) donde se almacena todo el historial y los archivos de los proyectos.
